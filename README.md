## My process

I started by planning the overall structure of the website, sketching the layout and identifying the main tools and resources I would need for the project.

Next, I built the HTML structure, focusing on semantic elements and organizing the content in a clear and meaningful way. Once the structure was defined, I created and organized the classes I would use to style and control each section.

Finally, I moved on to the CSS, developing the visual design, layout, spacing, typography, and responsive behavior for different screen sizes.

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox
- CSS Grid

### What I learned

Through this project, I strengthened my understanding of semantic HTML and how to structure a webpage in a clear and organized way.

I also practiced using CSS Flexbox to create and align layouts, as well as media queries to make the design responsive across different screen sizes.

Another important part of the process was learning how to organize CSS using classes and custom properties, making the code easier to maintain and adjust.


### Continued development

In future projects, I want to become more comfortable using CSS Grid and improve my ability to create responsive layouts more easily and efficiently across different screen sizes.

### AI Collaboration

I used ChatGPT, Gemini and Cloude throughout the project as a learning and problem-solving tool.

I mainly used it to clarify CSS concepts, troubleshoot layout and responsiveness issues, and understand why certain solutions worked or didn't work. I also used it to brainstorm possible approaches when I got stuck.

What worked well was using AI to explain concepts and help identify problems in my code while allowing me to implement and test the solutions myself. This helped me better understand the reasoning behind the code rather than simply copying a solution.
